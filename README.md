# Tambo Break

Miniweb / minijuego hecho para GitHub Pages. No usa librerías externas ni necesita servidor.

## Archivos
- `index.html`
- `style.css`
- `script.js`

## Publicarlo en GitHub Pages
1. Crear un repositorio nuevo en GitHub.
2. Subir `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama **main** y la carpeta **/(root)**.
6. Guardar. GitHub mostrará la URL pública.

## Incluye
- estética nocturna de tambo con vacas, tractor, silo y granero animados;
- botón que se escapa;
- ordeñe ficticio contrarreloj;
- minijuego para esquivar obstáculos y juntar leche;
- vaca jefa con interrogatorio absurdo;
- sonidos generados por el navegador;
- confetti de vacas/leche al terminar;
- selección de premio y botón para copiar el reclamo.

Todo funciona también en celular.
