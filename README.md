# Tambo Break — final MUU-256

Miniweb/juego para GitHub Pages. No necesita librerías, servidor ni instalación.

## Archivos
- `index.html`
- `style.css`
- `script.js`

## Qué incluye
Cinco pruebas absurdas del tambo y un final de criptografía por capas. El jugador recibe pistas opcionales y debe romper cada capa antes de revelar el mensaje secreto.

La solución no está documentada aquí para no arruinar el juego.

## Publicar en GitHub Pages
1. Crear un repositorio.
2. Subir `index.html`, `style.css` y `script.js` a la raíz.
3. Abrir **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar `main` y `/ (root)`.
6. Guardar y abrir la URL que GitHub Pages genere.
