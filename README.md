# Tambo Break — Deck Protocol

Mini juego web para GitHub Pages.

## Archivos
- `index.html`
- `style.css`
- `script.js`

No usa librerías externas.

## Cómo publicarlo en GitHub Pages
1. Crear un repositorio nuevo.
2. Subir `index.html`, `style.css` y `script.js` a la raíz.
3. Ir a **Settings → Pages**.
4. Elegir **Deploy from a branch**.
5. Seleccionar `main` y `/ (root)`.
6. Guardar y abrir la URL que genera GitHub Pages.

## Qué incluye
- Aventura por turnos con mazo de cartas original.
- Energía, vida, escudo, cartas de ataque/control/curación y cartas “Dúo”.
- Cuatro enemigos rurales y recompensas para mejorar el mazo entre combates.
- Preguntas ligeras sobre la pareja que cargan “Energía Dúo”.
- Boss final criptográfico de cuatro capas.
- En cada capa del cifrado, al tercer intento fallido se revela el tipo de cifrado y una explicación concreta de cómo decodificarlo.
- Mensaje final oculto hasta completar las cuatro capas.
